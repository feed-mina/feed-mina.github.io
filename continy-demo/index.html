한 문장이 콘티가 되고,
콘티가 숏폼이 됩니다.

기획(콘티) → 장면별 프롬프트 → 영상 생성 → 자막·편집 → 업로드 준비를 한 화면 흐름으로 묶었어요. 아래 6단계를 순서대로 눌러 보세요.

  1. 요청 입력
  2. 장면 콘티
  3. 캐릭터·고정 규칙
  4. 영상 생성
  5. 자막·완성본
  6. 업로드 키트

1단계

만들고 싶은 영상을 평소 말하듯 적어 주세요

  1. 요청 이해 목적·길이·분위기·마지막 문구를 정리합니다
  2. 장면 자동 분리 전체 시간을 장면별로 나누고 흐름을 만듭니다
  3. 모델별 준비 장면마다 영상 프롬프트를 조립합니다

실제 서비스에서는 이 단계에서 AI가 요청을 읽고 콘티를 씁니다. 체험판은 미리 만들어 둔 예시 콘티를 보여 드려요.

2단계

장면 콘티를 검토하고 승인하기

가져온 장면은 모두 검토 필요 상태로 시작해요. 승인된 장면만 영상 생성으로 넘어갑니다. 장면을 누르면 실제로 조립되는 영어 프롬프트를 볼 수 있어요.

    3단계

    캐릭터 시트와 고정 규칙

    장면마다 인물 얼굴·옷·색감이 바뀌는 문제를 막으려고, 모든 프롬프트에 같은 기준을 붙여요.

    캐릭터 시트 · 에이니

    기본 정보
    20대 중반 여성, 가상 인물
    외형
    어깨까지 오는 흑갈색 머리, 맑은 피부, 아이보리 니트
    스타일
    자연광, 부드러운 파스텔, 필름 같은 결

    고정 규칙

    • 모든 장면에 같은 캐릭터 시트를 참조
    • 로고·글자를 영상 안에 그리지 않기 (자막은 편집에서)
    • 마지막 장면 끝 프레임 = 첫 장면 시작 프레임 (반복 재생 연결)
    • 손가락·얼굴 왜곡이 보이면 그 장면만 다시 생성

      5단계

      단어 자막을 얹은 완성본 미리보기

      정지 컷은 카메라 무브로 움직이고, 장면 사이는 크로스페이드로 이어 붙여요. 말소리는 단어 단위로 시간을 맞춰 자막이 한 단어씩 강조됩니다.

      Continy 체험판 미리보기

        실제 완성본은 렌더 서버가 MP4로 만들어요. 체험판은 장면 색과 자막 타이밍만 흉내 냅니다.

        6단계

        업로드 키트

        콘티 내용으로 유튜브 쇼츠·인스타그램 릴스에 붙일 제목, 설명, 태그를 자동으로 만들어요.

        실제 Continy는 이렇게 동작해요

        • 화면 Next.js 호환 vinext · React 19 · Tailwind
        • 서버 Cloudflare Workers · D1 · R2 · Durable Objects
        • 생성 fal.ai · Replicate 영상 모델, 외부 영상 가져오기
        • 렌더 컨테이너에서 FFmpeg로 크로스페이드·단어 자막 합성
        • 안전장치 승인된 장면만 생성 · 비용 한도 자동 정지 · 실패 장면만 재시도

        체험판은 서버와 통신하지 않는 정적 페이지예요. 계정·비밀값·결제 정보가 하나도 들어 있지 않습니다.
