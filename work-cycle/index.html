work-cycle | 회의록·칸반·주간보고를 연결한 업무 관리 도구

회의에서 정한 일이 어디까지 진행됐는지 확인하고, 주간보고에 필요한 기록을 한곳에서 찾을 수 있도록 회의록·칸반·보고 화면을 연결했습니다.

민예린 · 업무 기록 흐름 설계·웹 구현 · 2026년 11월 16일

로그인 없이 기본 기능 체험하기회의록으로 시작하는 3분 안내

회의록에서 주간보고까지

  1. 1. 회의록에서 할 일 확인

    회의에서 무엇을 정했고 다음에 무엇을 할지 예시 회의록에서 확인합니다.

    예시 회의록 열기

  2. 2. 칸반으로 진행 상태 추적

    할 일을 카드로 보고 우선순위와 진행 상태를 확인합니다.

    예시 칸반 열기

  3. 3. 주간보고로 결과 정리

    한 주의 진행 내용과 다음에 할 일을 보고 화면에서 살펴봅니다.

    예시 주간보고 열기

어떤 문제를 어떻게 풀었나요?

회의록을 다시 읽지 않고 진행 상태를 확인하려면?
다음에 할 일은 칸반의 카드로 관리합니다. 회의록에는 결정 근거를 남겨 필요할 때 확인할 수 있게 했습니다.
주간보고는 어떤 기록을 사용하나요?
운영 설계는 일정, 검증, 회고 기록을 진행사항과 예정으로 모읍니다. 금주 목표를 따로 적지 않으면 우선순위가 높은 칸반 카드 제목을 활용합니다.
로그인 없이 어디까지 체험할 수 있나요?
기본 체험판에서 회의록, 칸반, 로드맵, 주간보고를 예시 데이터로 볼 수 있습니다. 체험판에서 입력한 기록은 현재 브라우저에 저장됩니다. 회의 요약과 공유 링크는 예시로 체험합니다.
